Cara Pemasangan di Google Apps Script:
    Buka Google Apps Script Editor.
    Buat proyek baru (New Project).
    Ganti isi file Code.gs bawaan dengan kode berkas Code.gs di atas.
    Buat file HTML baru dengan nama index (index.html) lalu tempelkan seluruh kode dari index.html di atas.
    Klik Deploy > New Deployment > Pilih tipe Web app.
    Atur Execute as: Me dan Who has access: Anyone.
    Klik Deploy dan salin URL Web App yang dihasilkan.
